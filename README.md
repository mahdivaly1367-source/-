# فرکانس خاموش: پروندهٔ نوار سیزدهم
### (Silent Frequency: Case of Tape 13)

یک بازی ماجراجویی داستان‌محور اشاره و کلیک (Point & Click Adventure) به زبان فارسی، با فضاسازی سینمایی، واقع‌گرایانه و معماهای مبتنی بر شواهد صوتی و اسناد آرشیوی.

---

## ۱. معرفی اجمالی پروژه
- **عنوان بازی:** فرکانس خاموش: پروندهٔ نوار سیزدهم
- **ژانر:** ماجراجویی اشاره و کلیک / معمایی کارآگاهی / درام رازآلود (Narrative Mystery / Audio Investigation Point & Click)
- **شخصیت اصلی:** آوا راد، مرمت‌گر نوارهای صوتی مغناطیسی
- **فضای داستان:** شهری ساحلی در حاشیه دریای مازندران (بندر کهن مه‌آب)؛ پاییز بارانی، یک ایستگاه رادیویی مخابرات دریایی رو به تخریب.
- **موتور و فناوری:** React 19 + TypeScript + Tailwind CSS v4 + Motion (Vite Runtime). معماری بر پایه داده و ماشین وضعیت (State Machine) صریح.
- **رویکرد مهندسی:** توسعه مبتنی بر مشخصات (Spec-Driven Development - SDD).

---

## ۲. وضعیت فعلی پروژه
- **مرحله کنونی:** فاز ۱ — برش قابل‌بازی استودیو و ناوبری (Phase 1)، در حال تکمیل و آزمون.
- **قابلیت‌های پیاده‌سازی‌شده:** حرکت کلیکی آوا روی چندضلعی مجاز؛ انتقال کلیک خارج از محدوده به نزدیک‌ترین مرز قابل‌حرکت؛ مقیاس پیوسته بر اساس عمق؛ لنگر پا روی ۹۶٪؛ جهت‌های مختلف و فریم‌های راه‌رفتن؛ هات‌اسپات‌های قابل بررسی با متن و آیکون متناسب؛ پنل دیباگ برای نمایش چندضلعی حرکت و هات‌اسپات‌ها با `Ctrl+Shift+D`.
- **محدودیت‌ها:** فقط صحنهٔ استودیو قابل بازی است. انتقال واقعی میان شش صحنه، Inventory، Journal، دیالوگ‌های شاخه‌ای، معماهای داستانی و ذخیره‌سازی هنوز پیاده‌سازی نشده‌اند. تصاویر فعلی SVGهای نمونه برای برش اولیه هستند و جایگزین پس‌زمینه‌ها و اسپرایت‌های نهاییِ سینمایی فاز هنری نیستند.
- **وضعیت کیفیت:** GitHub Actions روی آخرین commit `cf1d6e35caaf7d3d0e6f435d1de7e0b315de5b0d` موفق شد. نصب وابستگی‌ها، ۶ آزمون هندسهٔ ناوبری، ۴ آزمون مرورگری Playwright، بررسی TypeScript و بیلد تولید همگی سبز هستند. بازبینی هنری/بصری دستی هنوز انجام نشده و این آزمون‌ها کیفیت نهایی تصاویر را تأیید نمی‌کنند.
- **اسناد:** اسناد طراحی بازی، داستان، معماها، هویت بصری، مشخصات فنی، صحنه‌ها، آزمون‌ها، نقشهٔ راه، تصمیمات و گزارش کار در `docs/` موجودند.

10. [`docs/WORKLOG.md`](./docs/WORKLOG.md) — گزارش وقایع‌نگاری توسعه و اقدامات فاز صفر.

## ۴. ابزارهای مورد نیاز و روش اجرا
### نیازمندی‌ها:
- **Node.js:** نسخهٔ `20.19+` یا `22.12+` (موردنیاز Vite 8)
- **مدیر بسته‌ها:** npm یا bun

### اجرای محیط توسعه:
```bash
npm install
npm run dev
```
برنامه روی پورت `http://localhost:3000` در دسترس خواهد بود.

### اعتبارسنجی و بیلد:
```bash
npm run test:navigation  # آزمون هندسه حرکت و پرسپکتیو
npm run lint             # بررسی تایپ‌ها و عدم وجود خطای کامپایل
npm run build            # ایجاد بسته نهایی پروداکشن
```
