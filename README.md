# فرکانس خاموش: پروندهٔ نوار سیزدهم
### (Silent Frequency: Case of Tape 13)

یک بازی ماجراجویی داستان‌محور اشاره و کلیک (Point & Click Adventure) به زبان فارسی، با فضاسازی سینمایی، واقع‌گرایانه و معماهای مبتنی بر شواهد صوتی و اسناد آرشیوی.

---

## ۱. معرفی اجمالی پروژه
- **عنوان بازی:** فرکانس خاموش: پروندهٔ نوار سیزدهم
- **ژانر:** ماجراجویی اشاره و کلیک / معمایی کارآگاهی / درام رازآلود (Narrative Mystery / Audio Investigation Point & Click)
- **شخصیت اصلی:** آوا راد، مرمت‌گر نوارهای صوتی مغناطیسی
- **فضای داستان:** شهری ساحلی در حاشیه دریای مازندران (بندر کهن مه‌آب)؛ پاییز بارانی، یک ایستگاه رادیویی مخابرات دریایی رو به تخریب.
- **موتور و فناوری:** React 19 + TypeScript + Tailwind CSS v4 + Motion (Vite Runtime). معماری بر پایه داده و ماشین وضعیت (State Machine) صریح.
- **رویکرد مهندسی:** توسعه مبتنی بر مشخصات (Spec-Driven Development - SDD).

---

## ۲. وضعیت فعلی پروژه
- **مرحله کنونی:** فاز ۲ — اینونتوری و دفترچهٔ کارآگاهی (Phase 2)، در حال پیاده‌سازی و آزمون.
- **قابلیت‌های پیاده‌سازی‌شده:** حرکت کلیکی آوا با مهار پای کاراکتر؛ هات‌اسپات‌های قابل بررسی؛ اینونتوری با نوار سیزدهم آغازین، برداشتن فیوز ۲A و بررسی چرخشی اشیا؛ درگ‌ودراپ و بازخورد برای استفادهٔ نامتناسب؛ ثبت خودکار سرنخ‌ها؛ دفترچهٔ کارآگاهی با اتصال دو مدرک، فرضیهٔ موقت و راهنمای سه‌مرحله‌ای؛ پنل دیباگ با `Ctrl+Shift+D`.
- **محدودیت‌ها:** فقط صحنهٔ استودیو قابل بازی است. انتقال واقعی میان شش صحنه، دیالوگ‌های شاخه‌ای، میز صوتی و ذخیره‌سازی هنوز پیاده‌سازی نشده‌اند. فاز ۲ فقط وضعیت همان نشست مرورگر را نگه می‌دارد و ذخیرهٔ پایدار جزو فاز ۶ است. تصاویر فعلی SVG نمونه‌اند، نه دارایی‌های هنری سینمایی نهایی.
- **وضعیت کیفیت:** فاز ۱ پیش‌تر با ۶ آزمون هندسه و ۵ آزمون مرورگری، بررسی TypeScript و بیلد تولید تأیید شده بود. فاز ۲ سه آزمون Playwright اضافه می‌کند: جمع‌آوری و بازبینی فیوز، ثبت و اتصال سرنخ‌ها، و درگ‌ودراپ اشتباه بدون مصرف آیتم. نتیجهٔ نهایی باید از اجرای GitHub Actions خوانده شود؛ تا پیش از سبز شدن CI، فاز ۲ تکمیل‌شده تلقی نمی‌شود.
- **اسناد:** اسناد طراحی بازی، داستان، معماها، هویت بصری، مشخصات فنی، صحنه‌ها، آزمون‌ها، نقشهٔ راه، تصمیمات و گزارش کار در `docs/` موجودند.

## ۳. ساختار مستندات معماری و طراحی (`docs/`)

10. [`docs/WORKLOG.md`](./docs/WORKLOG.md) — گزارش ممیزی فاز صفر و گزارش توسعه و آزمون‌های فاز ۱.

## ۴. ابزارهای مورد نیاز و روش اجرا
### نیازمندی‌ها:
- **Node.js:** نسخهٔ `20.19+` یا `22.12+` (موردنیاز Vite 8)
- **مدیر بسته‌ها:** npm یا bun

### اجرای محیط توسعه:
```bash
npm install
npm run dev
```
برنامه روی پورت `http://localhost:3000` در دسترس خواهد بود.

### اعتبارسنجی و بیلد:
```bash
npm run test:navigation  # ۶ آزمون هندسه حرکت و پرسپکتیو
npm run test:e2e         # آزمون‌های مرورگری فاز ۱ و فاز ۲
npm run lint             # بررسی تایپ‌ها و عدم وجود خطای کامپایل
npm run build            # ایجاد بسته نهایی پروداکشن
```
