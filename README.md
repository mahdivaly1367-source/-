# فرکانس خاموش: پروندهٔ نوار سیزدهم
### (Silent Frequency: Case of Tape 13)

یک بازی ماجراجویی داستان‌محور اشاره و کلیک (Point & Click Adventure) به زبان فارسی، با فضاسازی سینمایی، واقع‌گرایانه و معماهای مبتنی بر شواهد صوتی و اسناد آرشیوی.

---

## ۱. معرفی اجمالی پروژه
- **عنوان بازی:** فرکانس خاموش: پروندهٔ نوار سیزدهم
- **ژانر:** ماجراجویی اشاره و کلیک / معمایی کارآگاهی / درام رازآلود (Narrative Mystery / Audio Investigation Point & Click)
- **شخصیت اصلی:** آوا راد، مرمت‌گر نوارهای صوتی مغناطیسی
- **فضای داستان:** شهری ساحلی در حاشیه دریای مازندران (بندر کهن مه‌آب)؛ پاییز بارانی، یک ایستگاه رادیویی مخابرات دریایی رو به تخریب.
- **موتور و فناوری:** React 19 + TypeScript + Tailwind CSS v4 + Motion (Vite Runtime). معماری بر پایه داده و ماشین وضعیت (State Machine) صریح.
- **رویکرد مهندسی:** توسعه مبتنی بر مشخصات (Spec-Driven Development - SDD).

---

## ۲. وضعیت فعلی پروژه
- **مرحله کنونی:** فاز ۴ — جریان روایی و اتصال شش صحنه پیاده‌سازی اولیه شده؛ معماهای بهمن و دریچهٔ زیرکف در آزمون مرورگری هستند.
- **قابلیت‌های پیاده‌سازی‌شده:** حرکت و تعامل؛ اینونتوری و دفترچه؛ میز صوتی و رونوشت شاخه‌ای؛ شش صحنهٔ داده‌محور با مسیرهای بازگشت؛ جمع‌آوری شواهد فیوز/ثبت کشیک/ابزار؛ گفت‌وگوی شرطی بهمن و کلید فانوس؛ دیدار خسرو و دیاپازون ۴۴۰ هرتز؛ قفل زیرکف با شرط ارتعاش و رمز ۱۳۵۹؛ و پایان روایی پس از بازیابی نوار مستر.
- **محدودیت‌ها:** صحنه‌ها اکنون قابل پیمایش‌اند اما پس‌زمینه‌ها SVGهای برداری نمونه‌اند و جایگزین هنر نهایی نقاشانه/سه‌بعدی نیستند. صدای نوار اصلی و صدای گویندگان هنوز ادغام نشده و میز صوتی از سیگنال مصنوعی برای آزمایش فیلتر استفاده می‌کند. ذخیره‌سازی پایدار در فاز بعدی قرار دارد.
- **وضعیت کیفیت:** فاز ۱ تا ۳ در Quality Gate قبلی سبز بودند. فاز ۴ اکنون چهار آزمون اضافه دارد: اتصال گراف شش صحنه، خروج بدون کلید، باز شدن گفت‌وگوی بهمن با سه قرینه، و بازیابی نوار مستر/پایان. نتیجهٔ CI برای نسخهٔ فاز ۴ هنوز در حال اعتبارسنجی است؛ موفقیت کامل را پس از اجرای سبز کل مجموعه ثبت می‌کنیم.
- **اسناد:** اسناد طراحی بازی، داستان، معماها، هویت بصری، مشخصات فنی، صحنه‌ها، آزمون‌ها، نقشهٔ راه، تصمیمات و گزارش کار در `docs/` موجودند.

## ۴. ابزارهای مورد نیاز و روش اجرا
### نیازمندی‌ها:
- **Node.js:** نسخهٔ `20.19+` یا `22.12+` (موردنیاز Vite 8)
- **مدیر بسته‌ها:** npm یا bun

### اجرای محیط توسعه:
```bash
npm install
npm run dev
```
برنامه روی پورت `http://localhost:3000` در دسترس خواهد بود.

### اعتبارسنجی و بیلد:
```bash
npm run test:navigation  # ۶ آزمون هندسه حرکت و پرسپکتیو
npm run test:e2e         # آزمون‌های مرورگری فازهای ۱ تا ۳
npm run lint             # بررسی تایپ‌ها و عدم وجود خطای کامپایل
npm run build            # ایجاد بسته نهایی پروداکشن
```


## فاز ۵ — فضاسازی محیطی (در حال انجام)
لایه‌های جوی صحنه‌محور و صدای محیط مصنوعیِ اختیاری اضافه شده‌اند. پس‌زمینه‌های SVG فعلی هنوز دارایی نهایی سینمایی نیستند؛ تصویرسازی نقاشانهٔ نهایی، انسداد جلویی و ضبط‌های محیطی واقعی در کار باقی‌اند. جزئیات در `docs/ROADMAP.md` و `docs/WORKLOG.md` ثبت شده‌اند.
